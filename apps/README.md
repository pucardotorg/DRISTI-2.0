# Apps

Runnable builds for Dristi live here.

- **Individual / review builds** — short-lived apps or previews people can open to
  walk a design or user flow (usually on a branch / `build`, then merged when accepted).
- **Main product** — the integrated app that `main` converges on over time.

Do not keep every experiment forever on `main`. Absorb accepted work into the product
app; remove or archive temporary builds after review.

UI must use [pucar-design-system](https://github.com/neer-ideasbeforenoon/pucar-design-system)
only — see [../docs/design/](../docs/design/).

Nothing scaffolded yet; add the first app when building starts.
