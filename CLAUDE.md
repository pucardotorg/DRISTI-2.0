# Pucar Dristi 2.0

DRISTI is PUCAR's platform for running cheque-dishonour (Negotiable Instruments Act §138)
cases through Indian courts: one shared core, deployed per state with local rules/language
layered on top of identical national law. This repo is expected to become the codebase for
that product (or a related build) — currently empty aside from setup.

Full product context — domain model, national-vs-state split, state rollout status,
content model, legal source corpus, terminology — lives in **[docs/PRODUCT.md](docs/PRODUCT.md)**.
Read it before making product decisions; it's kept deliberately separate from this file so
everyday sessions don't load the full detail unless it's needed.
