# Pucar Dristi 2.0

DRISTI is PUCAR's platform for running cheque-dishonour (Negotiable Instruments Act §138)
cases through Indian courts: one shared core, deployed per state with local rules/language
layered on top of identical national law. This repo is expected to become the codebase for
that product (or a related build) — currently docs/orientation first.

**Docs map:** [docs/README.md](docs/README.md)

Read the relevant section there before making product decisions. Keep agent context light:
load only the docs you need for the task. Do not invent product personas or “who uses
DRISTI” assumptions — see [docs/open-questions.md](docs/open-questions.md). Domain actors
and the national §138 journey are under [docs/domain/](docs/domain/).
