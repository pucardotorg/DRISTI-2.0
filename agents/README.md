# Agents

Named agent workflows and prompts for this repo will live here as the work becomes
agentic (e.g. screen-from-journey, standards check).

Until a concrete workflow exists, keep this folder thin. Always-on guardrails stay in
`.cursor/rules/` — they apply whether or not a named agent is defined here.

Agents **read** `docs/product/` and `docs/design/`; they do not redefine product or brand
in chat.
