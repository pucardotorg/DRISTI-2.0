# Requirements (normative)

Snapshot: 2026-07-30. Source: [domain model site](https://dristidomain.netlify.app/)
(`data/requirements/<scope>.json` and the Requirements layer of the profile).

## What this layer is

The normative layer: what a system *must* do to run a case lawfully. Each statement is:

- traced back to the **provision** that requires it,
- intended to be **testable**,
- scoped to **National** + whichever **state** is active.

## What this repo keeps

Orientation only — how the layer works and where to look. The full checklist is large and
grows with states/case types; do not duplicate it in markdown. Pull current statements
from the domain site / requirements JSON when implementing or reviewing a feature.

Snapshot counts and how requirements bind product artifacts (fields, validation, screens,
etc.) are summarized in [../product-foundation.md](../product-foundation.md) §5.
