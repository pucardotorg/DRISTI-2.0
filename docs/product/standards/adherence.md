# Standards adherence

Snapshot: 2026-07-30. Source: [domain model site](https://dristidomain.netlify.app/)
(Standards adherence layer).

## What this layer is

The **non-legal** bar the build is measured against — separate from statutory
Requirements, though both constrain a court-facing vendor product.

Areas called out in the domain snapshot:

- Accessibility (WCAG)
- Security
- DPDP (India's data protection law)
- Performance
- Interoperability
- Usability / testing conformance

## What this repo keeps

Pointers and framing only. Full checklists and evidence live in the domain site data;
mirror or cite them when a build needs a concrete conformance matrix.
