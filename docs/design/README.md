# Design docs

How Dristi looks and behaves in product UI.

This folder is **guidance for this repo**. It does **not** contain the design-system
source code. Tokens, foundations, and UI primitives live in the shared
[pucar-design-system](https://github.com/neer-ideasbeforenoon/pucar-design-system)
repository. Dristi **consumes** that system; it must not grow a parallel UI kit.
